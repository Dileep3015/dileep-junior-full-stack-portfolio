# Dileep Kumar — Junior Full Stack Developer Portfolio

A distinctive dark technical portfolio built with React + Vite.

## Run in VS Code

1. Install Node.js LTS.
2. Extract the ZIP and open the project folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:
   npm install
5. Start:
   npm run dev
6. Open the localhost address shown by Vite.

## Build
npm run build
